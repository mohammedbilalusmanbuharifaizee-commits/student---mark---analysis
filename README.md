
# Student Mark Analysis

## Description
A simple Python program that analyzes student
marks in three subjects.

## Features
- Accepts student name and subject marks
- Calculates total marks out of 300
- Calculates average percentage
- Assigns a grade based on average marks
- Validates marks between 0 and 100
- Displays the final result

## Subjects
1. Python
2. Mathematics
3. English

## Grade System
| Average | Grade |
|---------|-------|
| 90-100  | A+    |
| 80-89   | A     |
| 70-79   | B     |
| 60-69   | C     |
| 50-59   | D     |
| Below 50| F     |

## How to Run
1. Install Python 3.
2. Download student_mark_analysis.py.
3. Open a terminal in its folder.
4. Run:

   python student_mark_analysis.py
